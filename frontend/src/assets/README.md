# Assets

- `images/` — صور ثابتة (بانرات، خلفيات، صور "من نحن")
- `icons/` — أيقونات SVG مخصصة (الأيقونات العامة من `react-icons`)
- `fonts/` — ملفات الخطوط لو رغبت في استضافتها ذاتياً بدل Google Fonts

> حالياً الخطوط (Cairo / Poppins) تُحمّل من Google Fonts في `index.html`،
> وصور المنتجات التجريبية من picsum.photos. عند ربط الباك إند تأتي الصور من `/uploads`.
